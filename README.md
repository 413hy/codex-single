# 三系统交易仓库

本仓库同步保存当前运行架构的三个独立系统：

- `single-analysis/`：统一选币、方向分析与信号发布系统，不持有交易 API 凭据，也不下单。
- `auto-trader-longtime/`：普通止盈止损交易执行系统，只读消费本地发布信号。
- `auto-trader-longtime-02/`：对冲交易执行系统，只读消费本地发布信号。

每个子目录都是独立 Python 项目，拥有自己的 `README.md`、`AGENTS.md`、依赖锁、测试和部署文件。部署时应保持三个项目的现有绝对路径，并分别创建虚拟环境；不要在仓库内共享运行数据库、日志或凭据。

## 安全边界

仓库不包含 `.env`、虚拟环境、SQLite 运行库、日志、锁文件、缓存或运行时备份。实际部署配置应从各项目的 `.env.example` 单独创建，且交易系统只能连接 Bybit Demo。

## 验证

进入对应子目录后，按该项目 `README.md` 中的命令运行 Ruff、mypy 和 pytest。三套服务的策略与操作约束以各自 `AGENTS.md` 为准。
