# 单一信号分析系统

本项目统一为两套交易系统分析方向，只能发布信号，不能下单或持有交易 API 密钥。仅隔离模型服务进程调用模型。凭据不能输出、提交，也不得输出模型认证文件。

最新用户流程：上海时间固定周期 → TradingView 公开数据发现并比较 BYBIT USDT 永续合约 → 初选 1—10 币及方向 → Bybit 公共数据精细复核并给出普通最终 1—3 个 LONG/SHORT → 读取 20 秒内、归属明确且 LOCKED 的双仓快照 → 与最终名单重合的双仓直接复用方向 → 额外双仓币抓取 TradingView 和 Bybit 数据判向（可 SKIP） → 同币每轮去重并发布共享 `signals.db` → 两个交易系统独立只读消费。不得恢复旧 Bybit 全市场评分扫描流程。主目标为未来 1—2 小时，一周仅作背景。正常有效数据不得返回空普通名单，首选必须 LONG/SHORT，可如实标低置信；数据或模型故障需显式失败，不伪造或二次调用。

信号按币种发布，发布后 **600 秒**有效；消费去重归交易系统，不重放旧信号制造成交。新分析 Bot 仅发通知，不复用交易 Bot。提示词修改须保留版本证据和真实模型验证。

频率默认 20 分钟，仅分析 Bot 可改为 10—1440 分钟且为 10 的整数倍。按 1970-01-01 上海时间 00:00 固定锚点连续计算；恢复或保存频率采用下一固定时间点，当前轮不中断，重启和长轮次错过的周期不补跑。币种详情按钮属于各轮通知内嵌键盘并固定原轮次；底部键盘只显示管理菜单。

验证：`.venv/bin/ruff check src tests`；`.venv/bin/mypy src`；`.venv/bin/pytest -q`。
