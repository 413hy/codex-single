# 单一信号分析系统

用户授权统一管理两套交易系统的选币与方向分析。本项目不能下单，不能持有交易API密钥。
仅模型服务进程可调用模型。默认20分钟，分析Bot修改统一频率；交易Bot不能修改。
对冲系统交易所快照必须新鲜（20秒内），只读取归属明确且LOCKED的双向仓位。
同币种每轮只判向一次；双仓币优先，不占普通1—3名额；普通首选必须明确LONG/SHORT，其他币SKIP等待下一轮，禁止二次追问。
信号按币种发布，发布后60秒有效。消费去重归交易系统；禁止重放旧信号来制造成交。
保持原筛选/模型证据和Schema约束；修改提示词必须留版本证据及真实模型验证。
新分析Bot只发分析通知，不复用交易Bot。凭据不输出、不提交；不得输出模型认证文件。
验证：.venv/bin/ruff check src tests；.venv/bin/mypy src；.venv/bin/pytest -q。
