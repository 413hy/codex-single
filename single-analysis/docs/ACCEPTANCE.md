# 当前重构验收

- 固定周期按上海时间锚点运行；分析 Bot 可改 10—1440 分钟且必须是 10 的整数倍；两交易 Bot 不管理分析频率。
- TradingView 是唯一全市场发现来源。旧 Bybit 全市场评分选币代码、CLI 入口和模型提示词不在生产路径。
- TradingView 初选 1—10 币，Bybit 复核正常最终 1—3 个明确 LONG/SHORT；数据或模型故障不伪造方向。1—2 小时为目标，一周只作背景。
- 对冲快照必须 20 秒内且双向、LOCKED、归属唯一。与最终名单重合直接复用；额外双仓另行分析，可 SKIP，不占普通名额。
- 同币每轮最多一次发布，600 秒有效。两消费者对共享 `signals.db` 独立认领、风控和执行；不重放旧信号。
- 真实生产轮次与两消费者结果见 [现场审计](refactor-20260926/LIVE-AUDIT.md)。版本和数据源说明见 [重构报告](refactor-20260926/REPORT.md)。
