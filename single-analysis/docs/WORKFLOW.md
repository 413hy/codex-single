# 当前信号分析流程

1. 分析 Bot 按上海时间固定周期调度，默认 20 分钟。暂停、重启和长轮次错过的时间点不补跑。
2. TradingView CEX 筛选器扫描 BYBIT USDT 永续合约，Bybit 公共合约清单核实可交易身份。TradingView 待审池最多 20 币，兼顾活跃合约和涨跌两侧。
3. 逐币采集 TradingView 同合约七周期技术快照、同市场排名、Ideas、币种聚合背景。第一阶段模型横向比较，初选 1—10 个币和大致方向。
4. 对初选币采集 Bybit 已收盘 K 线、技术指标、量价、盘口和近期成交样本，补充 TradingView 公开新闻。第二阶段模型给出最终 1—3 个 LONG/SHORT，目标为未来 1—2 小时，周线仅作背景。
5. 读取对冲系统 20 秒内 LOCKED 且归属明确的双向仓位。与最终名单重合的币直接复用方向；其他双仓币采集 TradingView 与 Bybit 数据并逐币分析，可 SKIP。
6. 按轮次及币种唯一 ID 写入共享 `signals.db`，发布后 600 秒有效。两套交易系统分别只读消费、持久去重，不重放旧信号；分析 Bot 发送本轮通知和固定轮次详情。

任何核心身份、行情、模型或双仓快照失败都记录异常，不用猜测数据补齐；候选页不可用则审计并剔除该候选。完整来源和限制见 [重构报告](refactor-20260926/REPORT.md)。
