# 当前模型分析流程

更新：2026-09-15，包含“十个中至少给出一个最有把握的小长线方向”的最新要求。

1. **每20分钟开始一轮**。频率只由分析Bot管理，两个交易Bot不再设置分析频率。
2. **嗅探已有双仓**。读取对冲交易系统的新鲜交易所快照，记录已经全额对冲、正在等待判向的币种；不读取普通交易系统仓位。
3. **程序准备10个候选**。沿用原扫描条件，采集10份公开市场证据；必要行情不足时明确报失败。
4. **模型一次横向排序**。比较10币的小长线量价趋势、周期关系及风险，选1—3个；第一名是本轮相对方向置信度最高的候选。允许注明低置信，不将相对排名当作高胜率。
5. **合并双仓名单**。双仓币额外加入、不占普通名额，重复币只保留一次，并重点标记。
6. **逐币进行完整方向复核**。一周15m/30m/1h/2h量价为主，近12小时短周期行情及当轮盘口/主动成交样本辅助。普通首选必须明确做多或做空；其他普通入选和额外双仓可以无方向。首选恰为双仓时同一次调用同时满足两种用途。每币每轮最多调用一次，不二次追问。
7. **发布60秒有效信号**。每币完成即发布，两套交易系统各自只读接收、去重。方向模型不决定数量、资金、杠杆和订单价格。
8. **交易与通知独立处理**。交易端检查仓位、资金、止盈可达性等；普通系统沿用止盈止损，对冲系统按自身对冲机制执行。分析Bot只发分析通知，各交易Bot只发交易通知。

正常完成的一轮至少包含普通首选的明确方向。模型报错、必要行情缺失或首选违反输出合同均为失败，不把空结果报作正常，不由程序伪造方向。明确方向不保证实际开仓，交易端可能因暂停、已有仓位或止盈不可达而跳过。
