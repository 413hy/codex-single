# 交易系统当前运行约定

本项目是 Bybit Demo 交易执行端。选币、TradingView/Bybit 方向分析、模型调用、分析频率和分析通知均由 /root/single-analysis 负责。本项目从共享 signals.db 只读消费 version=2 信号；信号发布后 600 秒有效，过期不执行。信号 ID 在本地交易账本中持久认领，重启不重放。交易 Bot 不提供选币或分析频率入口。

普通方向按本账户已有仓位、暂停状态、余额、合约精度、杠杆和数量约束独立判断；有效信号也可以因本端风控而跳过。只暂停普通新仓，不中断持仓管理。资金、杠杆、数量、订单和退出目标由本端程序及已保存设置确定，模型不决定这些参数。当前普通开仓不启用历史 TP 可达性过滤。

私有接口固定 Bybit Demo；保持独立账本与凭据。下单前持久化意图，未知响应先用原订单 ID 核对，不能因重启或旧信号重放再次下单。交易所仓位和订单是实时状态来源。异常告警与通知通过本端持久 outbox 发送。

普通端以 README.md 的执行边界为准；TP/SL 均为 Reduce-Only 保护，已有仓位继续监控与核账。

当前现场联调结果见 /root/single-analysis/docs/refactor-20260926/LIVE-AUDIT.md。
