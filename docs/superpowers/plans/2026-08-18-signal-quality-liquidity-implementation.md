# 信号质量与流动性优化实施计划

1. 扩展扫描配置与候选特征，应用 150 万 USDT/24h、5 万 USDT/30m、25 bps 三项准入条件。
2. 扩展完成 K 线证据，提供 1 周期收益、滚动高低点 ATR 距离、pivot 年龄和 30m 绝对成交额。
3. 调整分析 Prompt，使 15m/5m 决定近端方向，1h/4h 只提供背景，并加入急拉/急跌衰竭规则。
4. 在模型输出校验层加入对称的方向一致性检查；程序只拒绝证据冲突结论，不直接生成多空方向。
5. 将上一轮强信号查询限定为最近定时周期，并使用该周期的原始强信号结论进行比较。
6. 补充扫描、证据、FHE/TUT 方向一致性和“定时周期后插入紧急周期”的回归测试。
7. 运行 pytest、Ruff、mypy、配置检查、正式 Bybit 扫描、FHE 保存证据 no-notify 回放和 MCP/Telegram 灰盒测试。
8. 全部通过后提交代码，停止旧单实例服务，启动新版本并验证一个正式通知周期；失败则恢复旧提交和配置。
